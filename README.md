# TreadFleet

AI operations assistant for commercial tire crews in Canada. Technicians speak a note at the truck; the work order,
torque log, stock update and fleet invoice are prepared for the owner's approval.

This repository holds the public homepage and pilot program sign-up: https://punch-k.github.io/treadfleet/

- Bilingual (English / French)
- Pilot applications are stored in Canada (Supabase, Canada Central region), insert-only from the website
